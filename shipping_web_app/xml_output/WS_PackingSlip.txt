Packing Slip WebService
CONFIDENTIAL

Overview
The Packing Slip Web Service allows users to create a packing slip by order, sales work order or line item and to update packing slips.
The input to this web service varies by action – it can either be sales work order number or line item number or packing slip number
(internal only). If the Shipment Email Notification is configured, the Portal User will receive Shipping Notifications when appropriate.

Summary
Applies to Accounts and Suppliers. One or more line items can be contained in a packing slip. If a supplier is using, the line item
must be for that supplier. It is possible to modify the quantity shipped for these line items. If no quantity shipped is provided, the
quantity shipped will always be the quantity ordered. Packing Slip Cost can be assigned (for the entire packing slip) – if it is not
provided the shipping cost of the individual line items will be used to create the total ship cost for the packing slip. A Packing Slip
always has the same Ship To Address, if none is provided the Ship To Address for each line will be used.
Only applies to Suppliers. One or more sales work orders can be contained in a packing slip. It is not possible to modify the
quantity shipped for these line items – the quantity shipped will always be the quantity ordered. Packing Slip Cost can be assigned
(for the entire packing slip) – if it is not provided the shipping cost of the individual line items will be used to create the total ship
cost for the packing slip. A Packing Slip always has the same Ship To Address, if none is provided the Ship To Address for each line
will be used.
Only applies to Accounts. One or more orders can be contained in a packing slip. It is not possible to modify the quantity shipped
for these line items – the quantity shipped will always be the quantity ordered. Packing Slip Cost can be assigned (for the entire
packing slip) – if it is not provided the shipping cost of the individual line items will be used to create the total ship cost for the
packing slip. A Packing Slip always has the same Ship To Address, if none is provided the Ship To Address for each line will be used.
Applies to Accounts and Suppliers. One packing slip can be updated using the MarcomCentral (Printable) Internal ID or the
External ID (if provided by Client). These values are provided in response to any of the actions that Create a Packing Slip. If
consumed by a supplier, the packing slip must have been created by this supplier.
